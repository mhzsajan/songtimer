Export

Each target gets what it actually needs. AbleSet takes the .lrc alone — it turns every timestamp into a MIDI clip, so a second one would show the lyric twice. Remotion AI adds .ends.txt so lines clear when they are sung instead of being guessed from the next one. OBS gets a standalone .html: add a Browser Source, point Local file at it, and size it to your canvas.

Repeat lines are exported as one entry with several timestamps — [00:10.00][01:20.00]chorus — which is what both tools expect, and reloading it here restores each as its own row.
