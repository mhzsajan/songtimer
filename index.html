Export

One .lrc feeds both ends of the pipeline:
AbleSet — drop it on ableset.com/tools/lyrics-lrc to get a Live set with one MIDI clip per line.
Video — feed the same file to the Remotion renderer for a transparent lyric overlay.

Repeated lines are merged into a single entry with several timestamps — [00:10.00][01:20.00]chorus — which is how both tools expect a repeat, and reloading it here restores each occurrence as its own row.
